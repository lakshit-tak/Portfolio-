# 🚀 Personal Portfolio — Lakshit Tak

A modern, responsive personal portfolio website built with React and CSS to showcase my skills, projects, and contact information.

## ✨ Features

- 🎨 Modern dark and light themes
- 📱 Responsive design for desktop, tablet, and mobile
- 🧭 Responsive navbar with a mobile sidebar
- 👨‍💻 Hero section with introduction and profile image
- 🙋 About section with education and career focus
- 🛠️ Skills section with technology icons
- 💼 Projects section with horizontally scrollable project cards
- 📩 Contact section with Email, GitHub, and LinkedIn links
- 🎬 CSS animations and interactive hover effects
- 💾 Theme preference saved using LocalStorage

## 🛠️ Technologies Used

- React.js — UI components
- JavaScript — Functionality and interactivity
- HTML5 — Structure
- CSS3 — Styling, animations, and responsive layouts
- Vite — Development server and build tool
- LocalStorage — Theme preference persistence

## ⚙️ Installation and Setup

1. Clone the repository
```
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder
```
cd Portfolio
```

3. Install dependencies
```
npm install
```

4. Start the development server
```
npm run dev
```
